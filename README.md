# 🌸 Radha Rani — A Divine Digital Experience 🦚💗

> **A beautiful interactive web experience inspired by the divine love, grace and timeless beauty of Shri Radha Rani. 🌸✨**

A creative and immersive web project dedicated to **Shri Radha Rani**, combining elegant visuals, animations, music, interactive sections and a devotional aesthetic into one digital experience.

This project was created to transform a simple webpage into something that feels **peaceful, beautiful and emotionally meaningful.** 💗

## 🌸 About The Project

**Radha Rani** is an interactive devotional-themed website designed around the beauty and grace associated with Shri Radha Rani.

The experience focuses on:

🌸 Divine aesthetics
🦚 Radha-Krishna inspired visuals
✨ Smooth animations
💗 Heartfelt messages
🎶 Devotional atmosphere
🌌 Interactive visual effects
📱 Responsive web experience

Every section is designed to create a calm and beautiful digital atmosphere.

## 🚀 Run Locally

### 1. Clone the repository

```bash id="7m6jda"
git clone https://github.com/hackncode1020/radharani-16-08-2026.git
```

### 2. Open the project

```bash id="4e4fws"
cd radharani-16-08-2026
```

### 3. Install dependencies

```bash id="x0br3u"
npm install
```

### 4. Start the development server

```bash id="d3h9yq"
npm run dev
```

Open the local development URL shown in your terminal.
